# 製作班級學生資料清單

依 Google 試算表報名資料，依中文班／英文班／數學班／年級分組顯示學生清單，可切換顯示過敏、家長電話、緊急聯絡人，支援預覽列印。年級模式會以 CREC 名單表格樣式預覽／列印（標題、格線、欄寬；空白格淺綠底）。

**純前端**：可部署到 GitHub Pages；本機亦可搭配 `server.py` 代理讀取試算表。

## 使用方式

### 方式一：GitHub Pages

1. 將本資料夾推上 GitHub repo（例如 `enrollment`）。
2. 在 repo 設定啟用 **GitHub Pages**（Source: main branch）。
3. 開啟：`https://<你的帳號>.github.io/enrollment/`
4. 貼上試算表網址，按「載入試算表」。

試算表需設為「知道連結的任何人可檢視」。GitHub Pages 以 Google GViz 方式讀取，不需本機伺服器。

### 方式二：本機

```bash
python3 server.py
```

開啟：http://localhost:5002/

## 試算表欄位對照

| 用途 | 欄位 |
|------|------|
| 英文名／中文名／生日／年級 | C / D / E / G |
| 是否舊生（No＝新生紅字） | J |
| 家長1＋電話 | K / M |
| 家長2＋電話 | O / Q |
| 緊急聯絡人＋關係＋電話 | T / U / V |
| 過敏 | W |
| 中文班分組 | AA ＋ AB（字體偏好） |
| 英文班分組 | AC |
| 數學班分組 | AD |
| 才藝意願／自習室 | AF / AG |
| 年級表列印 | 英文名、中文名、年級、生日、中文課、字體、英文課、數學課、才藝、自習室、過敏、藥物、家長1/2、緊急聯絡人 |

## 檔案說明

| 檔案 | 說明 |
|------|------|
| `index.html` | 主頁（分組、顯示資料、預覽列印） |
| `server.py` | 本機伺服器（靜態檔＋試算表 CSV 代理） |
